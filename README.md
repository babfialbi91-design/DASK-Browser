# DASK Browser

متصفح ويب Windows أصلي مبني على محرك **Chromium** المضمّن عبر **CEF** (Chromium Embedded Framework). C++20 + CMake للواجهة الأصلية، وReact + TypeScript لواجهة المستخدم.

**المرحلة الحالية (4 — ميزات الاستخدام اليومي مكتملة):** طبقة المراحل 1+2+3 كاملة (نافذة أصلية + تبويبات + شريط أدوات RTL داكن + صفحة New Tab + جسر IPC آمن + حجب إعلانات ومتتبعات على مستوى الشبكة)، مضافاً إليها: تخزين محلي SQLite (مفضلة، سجل، تنزيلات، إعدادات) مع migrations، مفضلة كاملة (إضافة/تعديل/حذف/بحث)، سجل تصفح مع تعطيل ومدة احتفاظ، تنزيلات حقيقية عبر CEF (تقدم/إلغاء/فتح الملف/فتح المجلد)، تبويب خاص معزول تماماً عن التخزين، استعادة الجلسة، وصفحة إعدادات موسّعة.

## الإعداد والبناء خطوة بخطوة

```bat
:: 0) إن لم يكن cmake على PATH، أضف أولاً:
set PATH=D:\VS2022BuildTools\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin;%PATH%

:: 1) نزّل توزيعة CEF (~180 MB) إلى third_party/cef واكتب scripts/cef_root.txt
powershell -ExecutionPolicy Bypass -File scripts/download_cef.ps1

:: 2) Configure (استخدم Developer Command Prompt لـ VS أو أضف cmake إلى PATH)
cmake -S . -B build -G "Visual Studio 17 2022" -A x64

:: 2) بناء الواجهة (يتطلب Node.js 18+؛ مرة واحدة ثم عند تعديل الواجهة)
cd app\ui && npm install && npm run build && cd ..\..

:: 3) Configure (استخدم Developer Command Prompt لـ VS أو أضف cmake إلى PATH)
cmake -S . -B build -G "Visual Studio 17 2022" -A x64

:: 4) Build (Debug أو Release)
cmake --build build --config Release --parallel

:: 5) تشغيل
build\bin\dask_browser.exe
```

- مسارات CEF البديلة: `cmake -DCEF_ROOT="C:/path/to/cef_binary_..."` أو متغير البيئة `CEF_ROOT` أو ملف `scripts/cef_root.txt`.
- الـ CMake ينسخ ملفات CEF (libcef.dll وملفات .pak و locales) وصفحة الاختبار وناتج الواجهة (ui/) بجانب الملفات التنفيذية تلقائياً.

## المزايا الحالية (المرحلة 2)

- **تبويبات متعددة:** زر `+` أو `Ctrl+T` لفتح تبويب، `Ctrl+W` لإغلاقه، `Ctrl+Tab` للتنقل بينها. كل تبويب نافذة مضيفة Win32 أصلية تحت شريط الأدوات، وعملية renderer منفصلة لكل تبويب.
- **شريط أدوات RTL داكن:** تبويبات مع زر إغلاق، شريط عنوان ذكي (يُدخل URL أو يبحث في Google/ويكيبيديا/MDN… قابلة للتغيير من صفحة New Tab)، أزرار للخلف/للأمام/إعادة التحميل/الرئيسية.
- **صفحة New Tab:** شعار DASK، مربع بحث، اختصارات قابلة للتخصيص (تُحفظ مع الجلسة).
- **اختصارات لوحة المفاتيح:** `Ctrl+L` تركيز شريط العنوان، `Ctrl+T` تبويب جديد، `Ctrl+W` إغلاق، `Ctrl+R` إعادة تحميل، `Ctrl+Tab` تبويب التالي، `Alt+←/→` للخلف/للأمام.
- **جسر IPC آمن:** الواجهة تشتغل داخل CEF على `http://dask.ui/index.html` وتتواصل مع المحرك عبر `CefMessageRouter` (`window.cefQuery`). المحتوى الويب لا يمكنه الوصول إلى الجسر (403)؛ فتح التبويبات والروابط مقيّد بـ http(s).
- **جلسة خفيف:** روابط التبويبات المفتوحة + المحرك + الاختصارات تُحفظ في `%LOCALAPPDATA%\DaskBrowser\session.json`.

## الاستخدام اليومي (المرحلة 4)

### التخزين المحلي (SQLite)

- قاعدة بيانات `dask.db` في `%LOCALAPPDATA%\DaskBrowser\` عبر `winsqlite3.dll` (الموجودة في Windows نفسها — لا نسخ إضافية)، مع migrations مُرقّمة وكشف تلف وإعادة إنشاء تلقائية برسالة عربية في الواجهة.
- كل الوصول للقاعدة يتم على **خيط قاعدة بيانات مخصص** (طابور مهام) — لا إغلاق لنفس خيط CEF.
- **لا كلمات مرور، لا أنماط نموذج، لا محتوى صفحات** — المفضلة والسجل والتنزيلات والإعدادات فقط.

### المفضلة

- زر نجمة في شريط الأدوات (أو `Ctrl+D`) يضيف/يزيل الموقع الحالي؛ مع تعديل الاسم والحذف والبحث من تبويب "المفضلة" في الإعدادات. الإضافة upsert حسب الرابط.

### السجل

- تسجيل الزيارات (رابط + عنوان فقط) للصفحات http(s) غير الخاصة وغير الداخلية، مع دمج الزيارات المتتالية خلال 60 ثانية.
- **تعطيل التسجيل كلياً** و/أو **مدة احتفاظ** (7/30/90 يوماً أو دائماً) مع تقليم تلقائي عند البدء، وبحث فوري (حد 500 نتيجة)، ومسح كلي أو جزئي (آخر 7/30 يوماً) من تبويب "السجل".

### التنزيلات

- تنزيل حقيقي عبر `CefDownloadHandler`: اسم ملف منقّى (حروف ممنوعة، أسماء أجهزة محجوزة CON/COM1…، طول محدود) وتفادي التعارض بلاحقة ` (n)`.
- تقدم مباشر، **إلغاء** (`Cancel()` على خيط CEF)، فتح الملف (`ShellExecuteW` فقط عند الاكتمال ووجود الملف)، فتح مجلد التنزيلات، وحذف من القائمة — من تبويب "التنزيلات".
- **التبويبات الخاصة:** الملف يُحفظ على القرص (كما في كل المتصفحات) لكن **لا يُسجّل في القاعدة إطلاقاً** — لا أثر دائم في قائمة التنزيلات.

### التبويب الخاص

- `Ctrl+Shift+N` أو زر "تبويب خاص" في New Tab: `CefRequestContext` منفصل (كوكيز وذاكرة تخزين منفصلة تُتلف مع الإغلاق)، شارة "خاص" على التبويب، بلا زر مفضلة، ولا يُدخل في السجل ولا في حفظ الجلسة.

### الاستعادة والإعدادات

- استعادة تبويبات الجلسة السابقة عند التشغيل (قابلة للتعطيل).
- صفحة الإعدادات أعيد تنظيمها في تبويبات: **عام** (الاستعادة، محرك البحث)، **الخصوصية** (الدرع، القوائم، الاستثناءات، الكوكيز، مسح البيانات)، **المفضلة**، **السجل**، **التنزيلات**.

## ما الذي ستراه عند التشغيل؟

نافذة `DASK Browser` داكنة بحجم 1280×800: شريط تبويبات أعلى (تبويب New Tab جاهز)، تحته شريط عنوان وأزرار تنقل RTL، ثم منطقة محتوى الويب. العمليات الفرعية (renderer/gpu) تعمل عبر `dask_browser_subprocess.exe` وChromium sandbox **مفعّل**.

- الإغلاق: زر النافذة `X` أو إغلاق آخر تبويب → `CloseBrowser(true)` لكل تبويب → `OnBeforeClose` → `CefShutdown` بالترتيب الصحيح.
- إذا نقصت ملفات CEF أو حزمة الواجهة بجانب الـ exe تظهر رسالة خطأ واضحة بدل انهيار صامت.

## الخصوصية وحجب الإعلانات (المرحلة 3)

### ما الذي يعمل؟

- **حجب على مستوى الشبكة فقط** عبر `CefResourceRequestHandler`: طلبات المتتبعات/الإعلانات تُرفض قبل التنزيل (تم اختبارها فعلياً: 8/8 طلبات تتبّع من googlesyndication/doubleclick/analytics حُجبت). تُحجب طلبات الموارد الفرعية فقط — تحميل الصفحة الرئيسي (document) لا يُحجب أبداً لتفادي كسر المواقع.
- **محرك فلترة محلي** (`app/native/adblock/`): مجموعة فرعية موثّقة من صيغة Adblock Plus — `||`، `|`، `^`، `*`، وخيارات `$third-party, ~third-party, script, image, stylesheet, subdocument, xmlhttprequest, media, font, object, other, domain=, ~domain=, important` مع `@@` استثناءات. الأداء: تحليل 50k قاعدة في ~50ms، مطابقة ~0.02ms لكل طلب.
- **القوائم:** EasyList + EasyPrivacy من `easylist.to`، تُنزّل عبر WinHTTP، تُتحقق (حجم، عدد قواعد مقبولة)، وتُكتب ذرّياً (ملف مؤقت + استبدال). فشل التنزيل يُبقي النسخة السابقة. أول تشغيل بلا قوائم = لا حجب حتى أول تحديث يدوي من صفحة الإعدادات.
- **زر الدرع** في شريط الأدوات: تفعيل/تعطيل الحجب للموقع الحالي (استثناء يراجعه المستخدم من صفحة الإعدادات).
- **إحصائية حقيقية:** عدد المحجوب لكل تبويب (شارة على الدرع)، لكل موقع، وإجمالي للجلسة.
- **ملفات تعريف الارتباط:** حجب الكوكيز من طرف ثالث (افتراضياً مفعّل) عبر `CefCookieAccessFilter`.
- **مسح البيانات:** كوكيز الموقع الحالي أو الكل (التخزين في الذاكرة فقط).
- **لا تتبّع:** لا telemetry، لا سجل تصفح دائم، لا تخزين سحابي.

### حدود الحجب (موثّقة بصدق)

- **لا يوجد cosmetic filtering** — لا تُخفى عناصر الصفحة ولا تُزال؛ القواعد الجمالية (`##`) تُعدّ وتُتجاهل.
- القواعد ذات خيارات غير مدعومة (`$popup`, `$document`, `$csp`, `$generichide`, regex حقيقية...) تُتجاهل بأمان.
- مطابقة third-party ونطاق الأرجاع تستخدم تقريبًا لـ Public Suffix (آخر نطاقين) — قد تعامل بعض نطاقات الخدمة متعددة المستويات (مثل co.uk) بدقة أقل.
- قواعد `domain=` تقارن بالنطاق العلوي للتبويب فقط، وليس بكل إطارات الصفحة.

### صفحة الإعدادات

`http://dask.ui/settings.html` (تُفتح من زر "الخصوصية" في New Tab): تفعيل/تعطيل الحجب، حالة القوائم وتحديثها، قائمة الاستثناءات مع الإزالة، سياسة الكوكيز، ومسح البيانات — مع شرح أثر كل خيار.

## الاختبار

```bat
powershell -ExecutionPolicy Bypass -File tests\smoke_test.ps1
powershell -ExecutionPolicy Bypass -File tests\smoke_test.ps1 -SkipBuild   :: فحص الملفات + اختبارات محرك الفلترة فقط
```

اختبارات محرك الفلترة (`build\bin\dask_filter_tests.exe`) تغطي: الحجب، الاستثناءات، $important، خيارات third-party ونوع المورد وdomain، الفواصل والبدائل، تجاهل القواعد الجمالية وغير المدعومة، والتحقق من سلامة القائمة.

اختبارات طبقة التخزين (`build\bin\dask_storage_tests.exe`) تغطي: migrations، CRUD للمفضلة/السجل/التنزيلات/الإعدادات، دمج الزيارات، حدود البحث، منقّي أسماء التنزيلات والمسارات الفريدة، والتعافي من قاعدة تالفة.

```bat
build\bin\dask_storage_tests.exe
build\bin\dask_filter_tests.exe
```
